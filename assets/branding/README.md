# Wasalight branding assets

- `wasabi-logo.png` è il marchio trasparente derivato dal file fornito
  **Logo Wasabi esteso White.png**, ritagliato sui contenuti e ridimensionato
  senza alterarne colori o proporzioni.
- `boot-logo.png` usa lo stesso marchio bianco e verde, senza targa, così resta
  nitido e leggibile sullo sfondo Plymouth quasi nero.

Questi file sono gli asset di branding predefiniti delle installazioni
Wasalight e sono attribuiti a **Michele Moser · Wasabi Lightbulbfarm**.
